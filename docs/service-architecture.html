Kafka topic reference

The event backbone. Producers write a domain event to a Mongo outbox (collection event); Debezium MongoSourceConnector (Kafka Connect) encodes it as Avro via AvroConverter + Confluent Schema Registry (schema-registry.infra.svc:8081, required) with output.format.value=schema and publishes to the CDC topic; the orchestrator deserializes with KafkaAvroDeserializer (@Payload GenericRecord, reads fullDocument), drives the saga, and fans out Avro commands (serialized with KafkaAvroSerializer) to the per-service topics below. Schema Registry backs all inter-service Kafka events and the CDC connector — it must be running before the connector is registered or the orchestrator starts.
