# Typography — distinctive, free, self-hosted

Three families, each with one job. Don't mix them across roles.

| Role    | Family                               | Where                                              |
| ------- | ------------------------------------ | --------------------------------------------------- |
| Display | **Bricolage Grotesque** weight 900   | Hero titles, page numerals, big stamps             |
| Body    | **Cabinet Grotesk** Regular / Medium | Default body, buttons, cards                       |
| Mono    | **Departure Mono**                   | SKUs, order IDs, prices, timestamps, kicker labels |

## Type scale

<div style={{ display: 'flex', flexDirection: 'column', gap: 'var(--space-4)' }}>
  {[
    { token: '--type-display', family: 'var(--font-display)', weight: 900 },
    { token: '--type-h1', family: 'var(--font-display)', weight: 900 },
    { token: '--type-h2', family: 'var(--font-display)', weight: 900 },
    { token: '--type-body', family: 'var(--font-body)', weight: 400 },
    { token: '--type-small', family: 'var(--font-body)', weight: 400 },
    { token: '--type-mono', family: 'var(--font-mono)', weight: 400 },
  ].map((row) => (
    <div
      key={row.token}
      style={{
        display: 'flex',
        alignItems: 'baseline',
        gap: 'var(--space-4)',
        borderBottom: 'var(--border-thin)',
        paddingBottom: 'var(--space-2)',
      }}
    >
      <div
        style={{
          fontFamily: 'var(--font-mono)',
          fontSize: 'var(--type-small)',
          color: 'var(--muted-ink)',
          width: '10rem',
          flexShrink: 0,
        }}
      >
        {row.token}
      </div>
      <div
        style={{
          fontFamily: row.family,
          fontWeight: row.weight,
          fontSize: `var(${row.token})`,
          color: 'var(--ink)',
        }}
      >
        Ag Riso 01
      </div>
    </div>
  ))}
</div>

Fluid via `clamp()` — don't hard-code `font-size: 32px;`, pick the closest scale token.
