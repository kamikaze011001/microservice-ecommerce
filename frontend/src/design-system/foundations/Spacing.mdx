# Spacing — the rhythm

`--space-1` (4 px) → `--space-16` (64 px). Page margin defaults to `--space-6` / `--space-8`.
Don't introduce arbitrary `padding: 13px;` — pick the nearest step.

Only these steps exist — there is no `--space-5`, `-7`, `-9`, `-10`, `-11`, `-13`, `-14`, or
`-15`.
