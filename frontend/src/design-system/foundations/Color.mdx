# Color — risograph two-tone + one spot

Six tokens, deliberately few. **Restraint matters** — two-tone everywhere else is what
makes the orange punch. Don't introduce a fourth or fifth colour without a token + ADR.

## The one rule that matters

`--spot` = every CTA/focus/alert; `--stamp-red` = stamps & inspection marks only, never a
CTA.
